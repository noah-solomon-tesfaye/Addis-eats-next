# Addis Eats

Addis Eats is a food delivery web application focused on Ethiopian
dishes and delivery across Addis Ababa.

## Features

- Browse Ethiopian dishes and menu categories.
- Add dishes to the shopping cart.
- Update quantities and remove cart items.
- Sign in using phone number and password.
- Place and track orders.
- View order history and order status.
- Display delivery map information.
- Export order information to CSV.
- View dashboard analytics and kitchen orders.
- Receive order status updates through Server-Sent Events.

## Technology Stack

- Next.js App Router
- React
- Auth.js (NextAuth)
- Tailwind CSS
- Leaflet
- Recharts

## Requirements

- Node.js compatible with the installed Next.js version
- npm
